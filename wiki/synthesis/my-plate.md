# My Plate (personal action board)

Single place for everything that needs **your** attention — features, GTM, Olli intake, and agent handoffs — so nothing slips.

- Notion board: https://app.notion.com/p/8c6b81e137dc4bd1b4a77277d6fd0c78
- Ask Boss anytime: **“What’s next on my plate?”** → I rank open **Needs me** rows by Impact and give you one clear action.

## How it works

| Upstream (stays where it is) | What lands on My Plate |
|---|---|
| Projects Manager / feature work | Only the **next action that needs you** |
| GTM hub (`[[synthesis/gtm-growth]]`) | Priority items that need your decision or hands-on work |
| Olli intake packets | Parked research/engage follow-ups until you have time |
| Any agent handoff | A row so it can’t vanish in chat |

Statuses: **Needs me** · **Waiting** · **Parked** · **Done**

Agents add a row when they hand you something. You (or Boss on ask) mark Done when acted.

Features from Projects Manager are still being pulled in; GTM + intake already seeded.
